## 🛠️ Stack
Vite · JavaScript · ESLint

## 🚀 Setup
```bash
git clone https://github.com/Abhishek7258/sfaiwalacopy.git
cd sfaiwalacopy
npm install
npm run dev
```

Use `package.json` for the authoritative development/build/lint scripts.
